About

关于我

我是阿卷，计算机专业研一学生。本科阶段接触过一些编程课，但真正开始认真写前端是从去年冬天开始的——那时候我连 CSS 的盒模型都还讲不清楚，现在总算能独立做出一个像样的页面。

我习惯「边做边学」：先定一个具体的小目标（比如给页面加上深色模式），遇到不会的去查资料、动手验证，再把过程整理成笔记。这个小站就是其中一次练习的产物。

接下来我打算往工程化方向走：把 TypeScript 和 React 补上，然后尝试参与开源项目。如果你也在学前端，欢迎一起交流。
